# OCI SDK Upgrade Worklist

This worklist is derived from `v65.61.1-to-v65.110.0-upgrade-diff.md` and is grouped by SDK service so follow-on stories can take one service or shared hotspot at a time.

Priority hotspots called out by the audit story:

- `core`: `CreateSubnetDetails.Ipv4CidrBlocks` was added and `CidrBlock` is no longer mandatory.
- `psql`: `CreateDbSystemDetails.Credentials` became mandatory while OSOK already writes the field.
- `logging`: `CreateUnifiedAgentConfigurationDetails` changed and needs a dedicated follow-up review.
- `monitoring`: `CreateAlarmSuppressionDetails` gained `Level` and `SuppressionConditions`.
- `mysql`: `CreateDbSystemDetails`, `DbSystem`, `DbSystemSummary`, and `UpdateDbSystemDetails` expanded materially.
- `databasetools`: connection create/status models gained new runtime endpoint and runtime identity fields.
